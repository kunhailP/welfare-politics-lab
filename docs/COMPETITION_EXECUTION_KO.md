# 대회 실행 순서 — 웹 플랫폼 제공 크레딧 경로

2026-10-29 사용자 선택: **SocioVerse 웹 플랫폼의 제공 크레딧 사용**.
추가 외부 API 지출은 0원으로 유지한다. 현재 모델 호출은 0회이며 모델·설정·
실제 사용 가능 잔액·수집 상한은 아직 확인하지 않았다. 이 경로 선택만으로
`configs/campaign.json`의 생성 보류를 해제하지 않는다. 프로토콜 v7은 유지한다.

## 승부를 걸 질문

**사회경제 정보를 넣어 더 그럴듯해진 합성 복지 응답이, 실제 사람들의 소득집단별
수급자 판단도 더 정확히 재현하는가?**

복지 행정의 자격 판정이 아니라 복지 지원의 정당성에 관한 정치적 판단을 다룬다.
평균·분포와 집단별 수급자 대비를 같은 출력에서 비교하고, 명시적 소득 입력 감사와
반복·제시 방식 점검을 연결한다. 기존 페르소나 연구가 이미 다룬 일반적 집단 오차를
다른 자료에서 반복하는 것만으로 새 기여라고 주장하지 않는다. 실제 소득계급 갈등,
투표·정책 연합, 인간 소득의 인과효과를 측정했다고 확대하지 않는다.

파일럿의 형식 성공과 본 실험의 실증 가치는 다른 판단이다. 현재 파일럿은 전체
계수 설계가 rank34여도 주요 대비는 추정 가능하지만, 공개 평가기는 full rank를
요구한다. 파일럿 형식 검사를 주요 556명 결과 평가와 구분하고 이를 무리하게
동일한 점수 경로에 통과시키지 않는다. 두 번째 모델은 가능하면 시행하되 첫 모델의
유리한 결과를 보고 고르지 않는다.

## 판단을 바꾸어야 하는 경우

추가 비용 0원 조건에서 계획한 수집과 필요한 점검을 완료할 수 없다면, 결과를 보기
전에 자원용 표본 옵션을 선택하고 변경 이유를 버전으로 남긴다. 실제 출력 이후에
유리한 집단·모델·지표만 선택하지 않는다. 일반적인 페르소나 오차만 재현되거나
결측·제시 방식에 따라 결론이 불안정하면 그 범위로 보고한다. 더 강한 주장을 쓰기
위해 통계량을 계속 늘리지 않는다. 수상 경쟁력은 실제 결과와 제출 완성도로 판단한다.
