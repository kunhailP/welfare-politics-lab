# 독창성과 실증 가치: 현재 판단과 다음 검증

작성일: 2026-10-30 KST. 인간 자료를 본 이후의 연구개발 메모다.
주요 모델 실험의 표본·대비·손실을 변경하지 않으며, 생성 보류도 유지한다.
이 문서는 독립 심사 결과가 아니라 연구팀의 판단이다.

## 질문을 좁히는 이유

“페르소나가 하위집단을 왜곡한다”는 결론 자체는 이미
[Taday Morocho 등](https://arxiv.org/html/2602.18462v1)의 연구와 겹친다.
“평균 일치만으로 충분하지 않다”는 주장 역시
[SSDataBench](https://doi.org/10.1073/pnas.2538145123)의 이변량·다변량 평가보다
새롭다고 말할 수 없다. 소득 문장을 빼는 조작이나 복지 자료로의 적용만으로
독창성이 입증되지는 않는다.

추가 검색에서 [Powdthavee의 소득별 구조 연구 v2 초록](https://arxiv.org/abs/2609.33055v2)을
확인했다. 인간 자료의 소득별 구조, 소득을 바꾸는 입력 실험, 소득 정보 제거와
다중 모델 비교까지 이미 다룬다. 해당 방법의 확인 근거는 현재 v2 초록이다.
버전이 지정되지 않은 PDF는 v2 초록과 내용이 달라 v2 전체를 읽었다고 기록하지 않는다.
또한 [FairFund-Bench](https://aclanthology.org/2026.findings-emnlp.1340/)는
지원의 필요 원인에 따른 deservingness와 평가 형식을 이미 다룬다. 따라서
복지 맥락, 소득 생략, 형식 민감도를 조합했다는 사실만으로도 독창성은 확립되지 않는다.

현재 남겨둘 만한 질문은 다음과 같다.

> 합성 응답자에게 사회경제 정보 묶음을 추가하면, 수급자의 소득에 따른
> 지원 판단과 그 판단의 응답자 계층별 차이를 인간 자료에 더 가깝게 재현하는가?
> 그 묶음 안에서 명시적 소득 정보의 추가는 어떤 차이를 만드는가?
> 같은 출력에서 어느 진단을 보면 그 판단을 지지하거나 철회해야 하는가?

주요 J_FN은 소득·고용위험·자녀의 **세 사실 묶음**과 무정보의 비교다.
명시적 소득 추가에 대응하는 F 대 F-I 및 J_FI는 원래 지정된 **보조 비교**다.
주요 결과를 소득 하나의 효과라고 부르거나, 소득 특이적 이야기를 위해 보조 결과를
사후에 주요 결과로 승격하지 않는다.

두 계층 모두 저소득 수급자에게 더 주는 패턴과, 그 추가 지원의 크기가
계층에 따라 다른 패턴을 구분한다. 이를 심리적 연대나 자기이익의 식별이라고
부르지 않는다. 사람의 소득은 무작위 배정되지 않았고, 현재 자료에는 경쟁
메커니즘을 식별할 직접 측정이나 처치가 없다.

## 먼저 실행한 인간 기준의 점검

원자료 Study1에서 완전한 4개 판단과 고/저소득 구분이 있는 사람은 1,458명이다.
확정 주요 표본 556명과 파일럿의 해당 25명을 제외한 877명은 사람 단위로 겹치지
않는다. 원자료는 이미 열람했으므로 이 877명을 미열람 검증자료라고 부르지 않는다.
모든 계산은 기존과 같은 36열 회귀설계와 대비를 사용했다. 단위는 CAD다.

| 사람 묶음 | 고소득 응답자의 수급자 30k−120k 대비 | 저소득 응답자의 같은 대비 | 저소득−고소득 응답자 차이 |
| --- | ---: | ---: | ---: |
| 확정 주요 556명 | 135.59 | 190.75 | 55.16 |
| 겹치지 않는 나머지 877명 | 248.88 | 369.50 | 120.62 |
| 완전 기록 고/저소득 전체 1,458명 | 200.55 | 291.48 | 90.93 |

나머지 877명에서 주요 표본과 같은 고소득304명·저소득252명을 비복원 추출하는
작업을 seed20261031로 500회 실행했다. 각 추출은 주요 표본·파일럿과 겹치지
않지만, 추출끼리는 겹친다. 사람을 바꾸면 그들의 수급자 과제도 함께 바뀐다.

- 양쪽 계층 각각의 30k−120k 지원 대비는 500개 추출 모두에서 양수였다.
- 계층 간 차이는 466개에서 양수, 34개에서 음수였다.
- 계층 간 차이의 중앙값은122.97, 5·95백분위는−7.97와265.77이었다.

이는 이 자료 안에서 구성한 표본들의 기술적 민감도다. 신뢰구간, 모집단 부호의
확률, 독립된500번의 실증 재현, 실제 AI의 오차 범위가 아니다. 완전 기록 선택의
소득 편향, 과제 구성과 원 연구 재구성 한계도 그대로 남는다.
주요 표본과 나머지의 차이는 계층 간 차이55 대121에 그치지 않고, 양쪽 계층의
수급자 소득 대비 자체에도 나타난다. 따라서 “공통된 패턴은 안정적이고 계층 차이만
불안정하다”고 일반화하지 않는다. 이500개 추출에서 확인한 것은 공통 대비의 양수
방향이 유지됐다는 제한된 사실이다.

**해석:** 이 점검에서 계층별 수급자 소득 대비의 양수 방향은 계층 간 차이의
부호보다 덜 민감했다. 따라서 55.16이라는 한 점의 부호를 AI가 바꿨다는 사실만으로
“인간에게 없던 계층 갈등을 만들었다”거나 정치적으로 중대한 왜곡이라고 결론내리지
않는다. 인간 기준을 유리한 표본으로 바꾸지도 않는다. 원래 고정 표본 점수는 유지하되,
더 넓은 정치적 해석에는 이 민감도를 함께 제시한다. 위 점검으로 새로운 인간사회의
복지 정치 발견을 주장하지 않는다.

재현 명령:

```bash
PYTHONPATH=src python scripts/audit_human_reference_stability.py \
  --cohort runs/development_08/prepared_inputs/evaluation_reference/cohort_linkage.tsv \
  --output runs/human_stability_new
```

`--cohort`는 기존 오프라인 재현에서 만들어진 같은 코호트 연결 파일로 바꿀 수 있다.
실행 기록은 `runs/human_stability_02/report.json`에 있다. 원자료와 사람별 추출 명단은
Git에 넣지 않는다. 이는 기존40개 산출물의 재현과 별도로 실행하는 보조 분석이다.
부호 집계는 부동소수점 영점 잡음을 제거하기 위해1e-8CAD를 수치 허용오차로 사용한다.
이는 정치적 중요성이나 동등성의 기준이 아니다. 이 수정으로 위 집계는 바뀌지 않는다.

## 구체적으로 어떤 해석이 달라져야 하는가

주요 인간 표본에서는 두 소득 계층의 수급자30k−120k 대비가 모두 양수다.
실제 모델에서도 두 대비가 같은 방향인데 크기만 다르면 그 크기의 불일치를 보고한다.
반면 사회경제 정보 입력 후 한 계층의 대비만 반대 방향을 보인다면, 이 합성 자료는
사람 기준에서 두 계층의 조정된 평균 판단이 같은 방향인 과제를 서로 대립하는
방향처럼 표현한 것이다. 그 판단은 해당 대비의 결측 범위와 반복·제시 방식 점검을
통과한 범위에서만 성립한다. 이는 미리 기대하는 결과가 아니라 구별해서 보고할 경우다.

이 해석은 이미 계산하는 양쪽 계층의 대비를 설명하는 방식이며 새로운 주요 점수를
추가하지 않는다. 모든 개인의 합의, 정책안에 대한 투표, 실제 복지 연합이나 인간의
계급갈등을 측정했다는 의미는 아니다. 이처럼 구체적인 해석도 실제 출력과 기존 연구의
비교에서 추가 가치를 보이지 못하면 독창성이 확보된 것으로 평가하지 않는다.

## 실제 모델 실험이 추가해야 할 증거

| 판단 | 비교 | 판단의 한계 |
| --- | --- | --- |
| 사회경제 정보와 명시적 소득이 각각 무엇을 바꾸는가 | 주요 F 대 N의 J_FN과 보조 F 대 F-I의 J_FI를 구분하고 각 계층의 대비도 보고 | F 대 N은 세 사실 묶음 효과; F-I는 명시적 소득만 지워 소득 추론 전체를 차단하지 않음 |
| 입력 소득 자체에 반응하는가 | 공통 과제에서 소득 표지만 바꾸는 별도 감사 | 모델 입력의 효과이며 인간 소득의 인과효과·고정관념 메커니즘은 아님 |
| 겉으로 맞는 결과가 정치적 해석에도 맞는가 | 같은 출력에 평균·분포·수급자 효과·계층별 조건부 진단을 모두 적용 | 일부 진단이 실패하는 사례를 선택해서 보이지 않음; 더 강한 진단이 잡으면 함께 보고 |
| 그 판단이 기록된 한 번의 우연인가 | 사전 지정된 반복 실행, 제시 방식 감사, 가능한 두 번째 모델 | 반복 수와 모델 범위를 넘는 보편성·안정성은 주장하지 않음 |
| 간단한 방법보다 무엇을 제공하는가 | 주요/파일럿과 겹치지 않는 인간 기록으로 학습한 통계적 비교모형 | 실제 인간 결과에 대한 접근이 다른 참고선이며 동등 자원 우월성 비교가 아님 |

마지막 통계적 비교모형은 **제안이며 미구현**이다. 개발 데이터는 남은877명으로
제한하고, 사람 단위 내부 검증·사용 특성·모형 종류·튜닝 규칙을 모델 결과 생성 전에
확정해야 한다. 주요556명의 인간 결과로 모형이나 하이퍼파라미터를 고르지 않는다.
이미 알려진 주 결과를 되맞추는 누출도 방지한다. 공개 원자료가 모델 사전학습에
포함되었을 가능성을 배제할 수 없으므로 “오염 없는 외부 예측”은 주장하지 않는다.

## 결과에 따른 기여와 중단 기준

1. 사회경제 정보 묶음 또는 보조 비교의 소득 입력이 두 계층의 수급자 대비와 계층 간 차이를 함께 인간 기준에 가깝게 하면,
   제한된 복지 판단 과제에서 조건화의 이득과 한계를 보고한다. 단순한 일치만으로는
   높은 독창성이라고 보지 않고 기존 연구 대비 추가 해석을 따로 심사한다.
2. 평균이나 일부 분포가 가까워져도 계층별 수급자 대비가 멀어지고, 입력 감사와
   반복·제시 방식 점검 후에도 그 평가가 유지된다면, 어떤 복지 정치 해석을 채택하면
   안 되는지 제시한다. “계층 갈등을 창조했다”는 제목을 먼저 정하지 않는다.
3. 실제 결과가 입력 효과보다 과제 구성·형식·결측에 크게 좌우되면 그 범위까지만
   결론낸다. 이를 인간의 계급정치에 관한 발견으로 포장하지 않는다.
4. 알려진 하위집단 오차를 복지 자료에서 다시 보여주는 수준에 그치거나, 자료의
   한계 때문에 추가 판단이 불가능하면 현재 질문을 우승권 기여로 평가하지 않는다.
   같은 결과에 지표를 더 붙이기보다 주제 또는 연구 질문 변경을 검토한다.

승부처는 “오류를 찾는 새 통계량”이 아니라, 사람 기준·명시적 입력 조작·대안 설명
점검을 연결했을 때 **합성 응답자로 어떤 복지 정치 결론을 지지할 수 있는지가
달라지는 실증 결과**다. 이 후보 기여는 아직 입증되지 않았다. 두 독립 AI 검토자의
평가 역시 실제 실험이나 외부 심사를 대신하지 않는다.

다음 설계 판단은 가까운 연구가 이미 보여준 것과 이번 과제가 추가할 수 있는 것을
나란히 쓴 비교표로 한다. 특히 Powdthavee 연구가 추가한 입력 실험까지 포함한 뒤에도
복지 과제에서 새롭게 달라지는 해석이 명료하지 않으면, 현재 설계는 엄밀한 응용
사례 연구 후보로만 남긴다. 새 논문의 부재를 확인했다는 주장이나 우승권 평가로
격상하지 않는다. 이 경우 대규모 생성보다 핵심 질문 재설계를 우선한다.
