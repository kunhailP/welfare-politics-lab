# 사람 자료 기반 비교모형: 결과와 한계

이는 실제 인간 자료로 학습한 통계적 예측의 평가다. 실제 AI 응답 실험도,
새 인간 조사도, 인위적으로 만든 정답표도 아니다. 모델 호출은0회다.
학습 전 사양은 커밋 `c91c8f3`에 보존했다. 다만 원자료·주요 인간 결과를
이미 본 이후의 설계이므로 사전등록·미열람 검증이라고 부르지 않는다.
세 모형을 모두 보고하며 결과에 따라 하나를 선택하지 않았다.

## 사람과 결과를 분리한 계산

주요·파일럿 후보와 사람 단위로 겹치지 않는877명, 판단3508건으로 학습하고,
기존 주요556명의2224개 과제에서 평가했다. 사람 중복은0명이다. 예측 함수에는
평가 대상의 정답 열을 제거해 전달한다. 평가 정답과 ID를 바꿔도 예측이 변하지
않는 검증을 통과했다. ID는 예측 특성이 아니다.

수급자8개 특성만 쓰는18계수 회귀, 응답자 소득별로 그 평가가 달라지는36계수
회귀, 학습 사람들의 평균만 쓰는 모형을 비교했다. 고용위험·자녀는 사용하지
않았다. 인간 학습 정답을 사용하므로 향후 LLM 조건과 정보 접근이 다르다.
동등한 자원에서의 우열 비교가 아니다.

단위는 CAD다. 각 집단 대비는 수급자 소득30k 대120k의 조정된 지원금 차이이며,
계층 간 차이는 저소득 응답자의 대비에서 고소득 응답자의 대비를 뺀 값이다.

| 자료/모형 | 고소득 응답자 대비 | 저소득 응답자 대비 | 계층 간 차이 | 계층 간 차이의 절대 오차 | 주요 과제 MAE |
| --- | ---: | ---: | ---: | ---: | ---: |
| 실제 주요 인간 자료 | 135.59 | 190.75 | 55.16 | 기준 | 해당 없음 |
| 다른 사람들의 평균 | 0.00 | 0.00 | 0.00 | 55.16 | 891.69 |
| 수급자 특성 회귀 | 303.52 | 303.52 | 0.00 | 55.16 | 844.22 |
| 소득별 평가 회귀 | 248.88 | 369.50 | 120.62 | 65.46 | 848.65 |

수치적 영점은 표에서0.00이며 원래 부동소수점 값은 실행 보고서에 보존했다.
예측은 연속 조건부 평균이다. 응답 궤적을 생성하거나 정수로 반올림하지 않는다.
미리 정한0–4000 범위 처리 규칙은 이번 주요 예측에 적용될 필요가 없었다
(세 모형 모두 범위 밖 예측0건). 이는 실제 LLM의 유효하지 않은 답변을
임의로 범위에 맞춰도 된다는 의미가 아니다.

## 무엇을 배웠는가

평균 모형은 수급자 소득을 구별하지 못하므로 두 집단 대비가 모두0이다.
그럼에도 계층 간 차이 하나에서는 소득별 회귀보다 인간 기준에 가깝다.
점수 차이는 약10.30CAD이고 중요성 기준이 없으므로 중대한 정치적 오류라고
평가하지 않는다. 단일 대비의 점수와 복지 판단 전반의 재현을 구별해야 한다는
자료 내 예시다. 새로운 수학이나 실제 LLM의 실패를 발견한 것이 아니다.

소득별 회귀가 더 복잡하다는 이유로 더 정확한 합성 응답자라고도 부르지 않는다.
모형들의 오차는 지표마다 다르며 전부에서 일관된 순위가 정해지지 않는다.
수급자 회귀의 차이가0인 것은 이번처럼 clipping이 없어 예측이 같은 가산적
선형 공간에 있을 때의 성질이다. 일반적인 소득 무정보 모델이 항상0이라는
뜻은 아니다. 비선형 응답이나 clipping에서는 과제 구성으로도 차이가 생길 수 있다.

학습 사람들 안의5분할 검증도 전 모형에 수행했다. 네 판단을 사람 단위로 묶었다.

| 비교모형 | 검증 RMSE | 검증 MAE |
| --- | ---: | ---: |
| 평균 | 1085.00 | 906.48 |
| 수급자 회귀 | 1052.92 | 854.93 |
| 소득별 회귀 | 1054.41 | 858.27 |

이 수치는 같은 원자료 안의 예측 점검이며 모집단 신뢰구간·모형 선택 근거로
사용하지 않는다. 소득별 회귀의 주요 대비가 나머지877명의 계수와 같은 것은
같은 선형 공간으로의 이식 성질이며, 별도의 인간 검증 성공이 아니다.

## 연구에 반영한 변경

기존 주요 점수는 유지했다. 공개 로그 평가에 두 계층의 대비·인간 기준 오차·
결측 응답의 정확한 선형 범위를 함께 추가했다. 주요 F 대 N은 세 사실 묶음,
보조 F 대 F-I는 명시적 소득 추가라는 구분도 유지했다. 사후 합성 점수나
성공 기준을 만들지 않았다. 고정 보고 표는 `EMPIRICAL_CLAIM_SPEC_V1.md`에 있다.

이 비교는 실용적 참고선의 공백을 줄였지만 기존 연구 대비 독창성이나 실제
LLM의 유용성을 입증하지 못했다. 지표·가상 사례·비교모형 종류를 더 늘리는
것은 다음 우선순위가 아니다. 실제 생성에 필요한 조건을 정리해야 한다.

```bash
PYTHONPATH=src python -m welfare_politics.statistical_references \
  --cohort runs/development_08/prepared_inputs/evaluation_reference/cohort_linkage.tsv \
  --output runs/statistical_references_new
```

코호트 파일은 기존 오프라인 재현에서 생성한 동일 파일로 대체할 수 있다.
실행 결과는 최종 검증 기록 `STATISTICAL_REFERENCE_VALIDATION.json`에 명시한다.
원자료·사람별 분할·예측행은 Git에 포함하지 않는다.
