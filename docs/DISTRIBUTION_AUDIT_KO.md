# 같은 출력에서 평가 기준이 무엇을 놓치는가 — v6

**이 문서의 대조 자료는 인간 응답을 사용해 만든 소프트웨어 검증이며,
실제 LLM 결과가 아니다.** 기존 원자료·핵심 표본·연구 가설은 바꾸지 않았다.

이전 대조 자료는 평균을 보존했지만 분포를 바꾸었다. 그러면 단순한 분포
점검으로도 쉽게 차이를 발견할 수 있다. 이번 검증은 원래 있던 응답값의
위치만 교환하여 그 약점을 보완한다. 새 정리나 기존 연구 전체에 대한
반증으로 주장하지 않는다.

## 실제 고정 설계에서 확인한 것

556명·2224개 판단의 동일한 행에서 다음을 확인했다. 모든 값은 평가용
소프트웨어 대조 결과이며, 오차막대나 통계적 유의성을 뜻하지 않는다.

| 확인 항목 | 인간 기록 그대로 | 증가 방향 대조 | 감소 방향 대조 |
| --- | --- | --- | --- |
| 바뀐 응답의 수 | 0 | 16 | 24 |
| 전체 배분액 분포와의 거리 | 0 | 0 | 0 |
| 소득집단별 배분액 분포와의 가중 거리 | 0 | 0 | 0 |
| 수급자 프로필별 배분액 분포와의 가중 거리 | 0 | 0 | 0 |
| 가법 회귀 설명력 R² | 0.0875375 | 0.0875375 | 0.0875375 |
| 핵심 계층 대비 γ, CAD | +55.16 | +129.71 | −22.03 |
| 소득집단×수급자 프로필별 분포와의 가중 거리, CAD | 0 | 14.45 | 18.15 |

여기서 γ는 수급자 소득30k 대120k의 배분 차이가 저소득 응답자와
고소득 응답자 사이에서 얼마나 다른지를 나타내는 고정 회귀 대비다.
감소 대조에서는24개 응답 위치만 바꾸어 그 방향을 뒤집었다.
인간의 심리적 동기, 캐나다 전체의 계층 갈등 또는 실제 정책 효과를
바꿨다는 뜻이 아니다. 이 유한 자료에서 계산하는 대비의 방향이다.

거리는 같은 수의 관측값을 정렬해 계산한 경험적 Wasserstein-1 거리다.
조건부 거리는 원래 셀의 행 수로 가중한다. ‘거리0’은 그 표의 해당
경험분포가 정확히 같다는 뜻이며, 검증 전반에 대한 합격 판정은 아니다.
행이 하나인 셀도 그대로 집계하므로 singleton 수를 함께 보고한다.
희소 셀의 거리를 모집단의 조건부 확률분포 추정치로 해석하지 않는다.
실제 고정 설계의 결합 조건은1788개 셀이며1418개가 singleton이다.
즉 약64%의 행이 그 조건에서 인간 응답 한 개와의 비교가 된다.
코드는 셀 크기 분포와 singleton 행 비율을 함께 출력한다.
조건을 더 세분하면 가중 W1이 기계적으로 커질 수도 있으므로,
거리 증가만으로 더 나은 모집단 검증이라고 판정하지 않는다.

## 보존 원리

서로 다른 두 수급자 프로필 A/B에서 고·저소득 응답자가 가진 금액이
각각(a,b)와(b,a)인 네 행을 찾는다. 각 프로필 안에서 두 금액을 맞바꾸면
원래 응답값만 재배치하면서 두 소득집단과 두 프로필의 응답값 묶음이
각각 보존된다. 전체 분포도 같다. 서로 겹치지 않는 교환만 사용한다.

고정된 가법 설계 Z에 대해 Z′y, y′y와 평균이 보존되어 회귀계수와
정의 가능한 R²도 보존된다. 고정된 상호작용 대비 w′y는 달라질 수 있다.
잔차의 개인별 배치, 군집 강건 표준오차, 기타 응답자 특성과의 관계 또는
소득집단×프로필 결합표 전체를 보존한다는 주장은 하지 않는다.
탐욕적 교환이므로 최적값이나 가장 나쁜 오류의 경계도 아니다.

## 비교 평가와 실패 응답

`recorded_responses`의 키 기반 분석에 다음을 연결했다.

- 전체·소득집단별·수급자 프로필별·두 조건의 결합별 분포 비교.
- 같은 셀과 행 수를 사용하는 평균 절대오차 범위.
- 결측 응답이 없는 경우의 가법 회귀계수·설명력 비교.
- 기존 핵심 대비와 J_FN/J_FI, 미응답 완성 범위.

미응답은 버리지 않는다. 계산용 기준값2000을 중심으로 셀 내 미응답
m개, 전체 n개일 때 거리 변화의 반경을2000m/n으로 제한한다. 이 값은
관측값을2000으로 대체했다는 뜻이 아니다. 삼각부등식에 따른 보수적
완성 범위이며, 최적 경계나 신뢰구간이 아니다. R²는 미응답이 있으면
전체 표본 값으로 보고하지 않는다.

## 연구 기여에 대한 판단

‘평균이 맞아도 틀릴 수 있다’보다 강한 검증이다. 어떤 저차 분포와
회귀 요약이 같아도 특정 계층별 배분 대비는 달라질 수 있음을 분리했다.
동시에 더 강한 결합 조건부 비교는 이를 발견한다는 사실도 공개한다.
우리 지표만 가능한 발견이라고 주장하지 않는다.

아직 실제 모델이 이러한 오류를 낸다는 증거는 아니다. 기존 벤치마크
전체를 그대로 재현한 비교도 아니다. 이후 동일한 실제 N/F/F-I 출력에
이 평가들을 함께 적용해, 복지 정치의 어떤 해석이 추가로 밝혀지거나
제한되는지 확인해야 한다. 이 비교 자체에는 새 모델 호출이 필요 없다.

재현: `scripts/reproduce.py`의 `distribution_preserving_control` 산출물.
개별 제어 배열은 원자료 파생물이므로 Git에 배포하지 않는다.
