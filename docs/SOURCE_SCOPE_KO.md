# 인간 기준의 범위와 선택 흐름

최종 새 문맥 검토자 두 명이 원자료와 코호트 연결표에서 주요 인간 대비를
독립 재계산했다. 통계 검토자는 참고모형·CV·500회 민감도도 별도로 재현했다.
이는 수치 교차검산이며 실제 LLM 결과나 새로운 인간 조사가 아니다.

| 단계 | 사람 | 판단 행 |
| --- | ---: | ---: |
| 공개 Study1 | 2295 | 9180 |
| 네 프로필 완전 사례 | 2003 | 8012 |
| 완전 사례 고·저소득 | 1458 | 5832 |
| 주요 후보 고·저소득 | 556 | 2224 |
| 파일럿 후보 고·저소득 | 25 | 100 |
| 주요·파일럿 제외 학습 | 877 | 3508 |

주요 후보 전체는768명, 파일럿 전체는32명이다. 중간·미보고 소득은 주요
고·저소득 대비에 포함하지 않는다. 네 프로필 완전 사례의 소득별 선택률:

| 응답자 소득 | 완전 사례/공개 사람 | 비율 |
| --- | ---: | ---: |
| 고소득 | 799/854 | 93.56% |
| 저소득 | 659/813 | 81.06% |
| 중간소득 | 384/438 | 87.67% |
| 미보고 | 161/190 | 84.74% |

따라서 주요556명을 국민 대표 표본이라고 부르지 않는다. 여기서 계층은 관측한
가구소득 범주의 조작적 의미다. 자산·직업·계층 정체성 전체를 측정하지 않았다.

아래는 수급자30k−120k 소득 대비의 고정 설계 회귀값이다. 단위는 CAD다.

| 코호트 | 고소득 응답자 대비 | 저소득 응답자 대비 | 저소득−고소득 차이 |
| --- | ---: | ---: | ---: |
| 주요556명 | 135.588 | 190.746 | 55.158 |
| 나머지877명 | 248.883 | 369.503 | 120.620 |
| 완전 고·저소득1458명 | 200.551 | 291.477 | 90.925 |

사람과 수급자 과제가 함께 바뀌므로 순수한 사람 선택 효과나 신뢰구간이 아니다.
주요 모델을 다른 코호트의 계수에 맞춰 재평가하지 않는다. 두 집단의 대비가
같은 방향이라는 사실은 모든 개인의 합의·정책안 지지·투표·복지 연합을 뜻하지 않는다.

배정 확률, 모집에서 공개까지의 제외, 원래 이름·언어·짝·UI가 완전히 복원되지
않았다. 시민권·고용 마진도 균등하지 않다. 인과 AMCE를 새로 식별했다고 하지
않고 복원된 과제의 동일 행·X에서 기술적 대비를 비교한다. 원 논문의 정치학적
가설 검증 결과를 뒤집는 분석도 아니다.
