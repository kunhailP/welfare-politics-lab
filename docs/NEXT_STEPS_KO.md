# 실제 실행 전 남은 작업

인계 시점의 실제 응답모델 호출은0회다. 다음 항목은 아직 완료되지 않았다.
사용자가 모델·설정·예산과 실행 방식을 결정해 이어서 진행한다. 이 문서는
추가 AI 승인을 요구하는 절차가 아니며, 구현·연구상 남은 일을 기록한다.

실행 경로는 웹 플랫폼 제공 크레딧으로 선택했다. 모델·잔액 설정은 사용자가 맡는다.
v0.3은 [입력 전용 ZIP 준비와 크레딧·공통 과제 로그 검증](PLATFORM_PREPARATION_KO.md)을
구현했다. 실제 웹 가져오기·호출·원문 내보내기 연결은 아직 해당 환경에서 확인해야 한다.

| 우선순위 | 작업 | 완료를 확인할 증거 |
| --- | --- | --- |
| 1 | SocioVerse 네이티브 study 실행·내보내기 또는 별도 runner 연결 | messages만 전송하고 모델·설정·예산·실행 버전을 동결 manifest로 결합; 실제 ID·응답·시도·비용 기록 |
| 2 | 생성 환경을 인간 평가 자료와 분리 | 생성 실행에 인간 결과·비교모형 정답·평가 파일 접근 권한이 없음 |
| 3 | 모델·디코딩·표본 규모·전체 지출 상한 고정 | `configs/campaign.json`을 실제 값으로 버전 관리; 플랫폼 잔액과 가격도 확인 |
| 4 | 파일럿의 전송·형식·실패·비용 점검 | 실제 원문과 전체 시도 기록; 실패 응답을 고치거나 정답으로 대체하지 않음 |
| 5 | 반복 실행·이름·짝짓기·A/B 감사의 live manifest와 로그 adapter | 같은 메시지도 다른 rollout/variant를 구분하고 사전 정한 비교를 모두 보존 |
| 6 | 구현된 공통 과제96개 keyed adapter에 플랫폼 원문 export 연결 | 오프라인 셀·A/B·모델·실패 기록 검증은 구현; 실제 웹 로그와 연결은 남음 |
| 7 | 본 실험 및 가능하면 두 번째 모델 | 주요/보조 점수·두 계층 대비·결측 범위·강한 조건부 진단을 동일하게 보고 |
| 8 | 결과의 새로움과 논문·시연 | 실제 결과가 가까운 선행연구에 무엇을 추가하는지 설명; 플랫폼 재현·시연 자료 |

기본 렌더러는 주요 계획의 rollout0을 만든다. 위 반복·표현 계획이 자동으로
실행되거나 모두 로그에 연결된 상태는 아니다. CLI 옵션을 이름만 바꾸어
기존 요청을 재사용하면 독립 실행이 되지 않는다.

파일럿 전체 계수 설계는 rank34지만 주요 대비는 추정 가능하다. 현재 공개
평가기는 full rank를 요구하므로 해당 파일럿을 그대로 점수화하지 못한다.
이는 대비 자체가 비식별이라는 뜻이 아니다. 파일럿의 형식·기록 점검과 주요
556명 결과 평가는 구분한다. rank가 부족한 분석을 임의로 바꾸지 않는다.

고용위험·자녀 관련 추가 비교는 프로토콜의 보조 연구 계획이다. 현재 주요
모델 로그 평가의 중심은 응답자 소득×수급자 소득 대비이며, 모든 보조 비교의
matched-design 수집·평가가 구현된 것은 아니다.

위 항목을 마쳐도 새로움이나 우승이 자동으로 따라오지 않는다. 기존의 일반적인
페르소나 오차를 이 자료에서 반복하는 결과라면 그 범위로 보고한다. 주요 점수가
조금 좋아지거나 작은 인간 대비의 부호가 바뀐 것만으로 정치적 발견을 주장하지 않는다.
