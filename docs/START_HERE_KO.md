# 복지 정치 연구 저장소: 현재 판단과 다음 실행

현재 연구는 **‘소득 정보를 준 합성 응답자가 복지 지지의 계층별 차이를
인간 자료에 더 가깝게 재현하는가’**를 검증한다. 수급자 심사 자동화가 아니라,
누구에게 얼마를 지원해야 하는지에 관한 정치적 태도의 분포를 다룬다.
소득집단 간 차이를 자기이익의 인과효과로 해석하지 않는다.

## 지금 완성된 것

- 업로드한 `dataverse.zip`의 해시를 고정하고 원자료를 수정하지 않는 분석 경로.
- 완전한 네 과제가 있는 응답자 중 파일럿32명과 후보768명의 분리.
  핵심 고·저소득 비교는556명·2224개 판단이며, 세 조건은3336개 쌍 요청이다.
- 인간 자료와 모델에 같은 설계·같은 행을 적용하는 비교 및 실패 응답의 범위 계산.
- 작성자·기존 대화·상대 평가를 보지 않은 독립 AI 리뷰어 두 명의 첫 검토와,
  각자 자신의 기존 평가를 보는 재검토. 원본 보고서와 수정 대응표를 보존했다.
- 모델을 호출하지 않는 재현 명령과 응답 순서·중복·정보 유출 방지 검증.

**실제 응답 모델 호출0회, 추가 유료 생성0회. 실증 모델 결과는 아직 없다.**
원자료와 논문 PDF는 배포 권한을 확인하기 전까지 Git에서 제외한다.

## v5에서 보강한 것

LASS 게재 수준은 엄밀성·독창성·깊이의 기준이다. 목표는 이번 대회의 경쟁력
있는 출품이며, 학술지의 결정을 기다리거나 목표를 바꾸겠다는 뜻이 아니다.
사용자는 그 기준에 도달하기 전 실험을 서두르지 않기를 원한다.

- 집단별 평균과 모든 수급자 프로필 평균을 보존하면서도 계층별 대비가
  바뀌는 정수 대조 자료를 만들었다. 실제 모델 결과나 새 이론은 아니다.
- 출판 설문과 프롬프트를 대조해 근거 없는 수급자 소득 단위 확장을 제거했다.
- 작은 파일럿의 행렬 전체 rank와 특정 대비의 추정 가능성을 구분했다.
- [분석 계획](ANALYSIS_PLAN.md)에 실제 출력에 적용할 비교와 반복·표현 감사를,
  [기여 판단 문서](CONTRIBUTION_AND_DECISION.md)에 공식 배점별 미해결 근거를 적었다.

후속 독립 재검토에서도 새 대조 자료만으로 증분 기여가 입증되지는 않는다는
지적이 나왔다. 이를 보존하고, 실제 과제에서 무엇을 더 알아낼지를 기준으로
개발한다. 파일럿과 본 실험의 생성은 현재 보류 중이다.

## 대회와 논문을 위해 무엇을 보여줘야 하나

독창성의 후보는 ‘페르소나가 편향된다’는 일반론이 아니다. 전체 평균 배분액과
계층별 배분 기준을 구분하고, 소득 문장의 추가·제거가 인간과의 오차를 어떻게
바꾸는지 같은 과제에서 직접 비교한다. 과제 구성만으로 생긴 집단 차이와
입력 소득에 대한 모델 반응을 별도의 공통 과제로 구분한다. 실패 응답 때문에
결론의 방향이 바뀔 수 있는지도 함께 보여준다.

결과를 보기 전에 다음 결과표를 고정한다.

1. 인간·N·F·F-I의 평균 배분액 오차와 핵심 계층 차이 오차. 평균이 비슷하다고
   ‘정치를 잘 재현했다’고 판정하지 않는다.
2. 소득 포함 조건의 절대오차 변화 J_FN, 소득 제거 대비 J_FI와 실패 완성 범위.
   음수는 이 유한 과제에서 더 가까웠다는 뜻이며, 실질적 성공의 기준은 아니다.
3. 공통 수급자 과제에서의 소득 라벨 차이와 이름·짝짓기 등 표현 점검.
   공통 과제의 가상 소득 라벨에는 대응하는 인간 정답이 없다.
4. 실제 모델 이름·설정·호출·실패 가중치·비용·재생 명령과 원자료 선택 한계.

두 리뷰어 모두 설계가 개선됐지만 본 실험 시작 조건이 남았다고 평가했다.
새로운 실증 결과 없이 우승 가능성이나 LASS 논문 수준이라고 판정할 수 없다.
실제 결과가 선행 연구보다 무엇을 추가하는지가 가장 큰 미해결 문제다.

## 다음 순서

1. SocioVerse에서 이 설계의 네이티브 실행·기록·내보내기가 가능한 경로를 확인한다.
   화면의 채팅 보조 모델과 시뮬레이션 모델을 구분하고 실제 모델 ID를 확인한다.
2. 플랫폼 크레딧을 먼저 검토하고 모델·예산·표본 크기를 고정한다.
   외부 유료 API 구매를 선행 조건으로 삼지 않는다.
3. 자료를 볼 수 없는 생성 환경에서 파일럿을 실행한다. 출력 형식뿐 아니라
   실패 가중치·반복 생성·표현 민감도를 점검하고 본 실험 조건을 동결한다.
4. 본 실험 후에는 유리한 방향의 결과만 남기지 않는다. 추가 기능보다
   두 번째 모델 검증, 실제 플랫폼 시연과 결과 재현을 우선한다.

현재 로컬 Git 저장소는 준비됐으며 GitHub 원격 저장소는 생성하지 않았다.
연결 계정은 `kunhail`, 의도한 대상은 `kunhailP/welfare-politics-lab`이다.
해당 계정으로 인증한 GitHub CLI 환경에서 아래 명령으로 비공개 저장소를
만들고 푸시할 수 있다. 실행 전 계정·커밋·배포 파일 검사가 수행된다.

```bash
python scripts/publish_github.py
python scripts/publish_github.py --execute
```

지속적인 검토는 [리뷰 절차](review/WORKFLOW.md)와
[미해결 작업 목록](RESEARCH_QUEUE.md)을 따른다. 이번 작업 밖에서 자동으로
모델을 호출하거나 검토가 계속되는 예약 작업은 설정하지 않았다.
