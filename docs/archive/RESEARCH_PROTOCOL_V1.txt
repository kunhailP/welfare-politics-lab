복지정치 연구 실행 설계 v1 — 2026-10-29
상태: 새 모델 생성 전 분석 계획. 인간 결과는 이미 검토했으므로 사전등록·미관측 인간 검증이라고 부르지 않는다. 이 문서는 설계이며 수상·논문 채택 또는 본 실험 결과가 아니다.

1. 연구를 한 문장으로
시민의 소득·고용 위험·가족 정보를 합성 시민에게 제공할 때, 실제 시민의 복지 배분 구조를 더 정확히 재현하는가, 아니면 전체 평균은 그럴듯하면서 집단별 이해관계를 왜곡하는가?
영문 가제: Do Synthetic Citizens Reproduce the Structure of Welfare Support?
수준: 복지정치의 측정 타당성과 에이전트 모델링 방법. 실제 신규 정책의 효과나 투표·정당·입법 연합을 추정하지 않는다.

2. 이론에서 구분할 것
(a) 지원의 전체 수준: 전반적으로 얼마를 배분하는가.
(b) 수급자에 대한 공통 판단: 수급자의 소득·고용·자녀·시민권 등에 얼마의 차이를 두는가.
(c) 시민별 판단 차이: 같은 수급자 소득 차이에 저소득 시민과 고소득 시민이 다르게 반응하는가.
세 가지는 서로 대체되지 않는다. 평균이 맞아도 (b)/(c)는 틀릴 수 있다. 시민 집단의 차이는 물질적 이해관계·사회적 친밀감과 관련될 수 있지만, 관측된 시민 소득의 인과효과나 심리적 동기를 이 자료만으로 식별하지 않는다.
자기 가구 소득과 수급자 개인 소득은 단위가 다르다. 이를 기계적으로 '같은 소득 집단 선호'로 코딩하지 않는다.

3. 최근접 연구 대비 기여의 조건
페르소나 유무의 차이, 합성 설문 재현, AI의 배분 편향 자체는 새롭지 않다. 제안 기여는 무작위 수급자 과제에서 평균·수급자 효과·시민별 효과 차이를 분리하고, 모델 입력 통제로 그 오류를 진단하며, 무효 응답이 허용하는 결론의 범위를 계산하는 재사용 가능한 평가 절차다.
이 조합의 구현만으로 독창성이 확정되지 않는다. 실제 모델 결과와 최근접 연구 대조가 기여를 뒷받침해야 한다.
관련: FairFund-Bench arXiv:2607.28934v2; Taday Morocho et al. doi:10.1145/3774905.3795477 / arXiv:2602.18462; Lee et al. arXiv:2610.05828; Ashokkumar et al. Nature s41586-026-10742-x.

4. 자료와 관측 단위
인간 자료: 업로드한 dataverse.zip, DOI10.7910/DVN/LPHMB7. 원본 해시 source_manifest.json에 보존.
출판된 최종 부록: published_supplement.pdf, 15쪽. 사전등록의 13쪽 모의 검정력 부록과 구분한다.
Study 1: 2,295명의 네 프로필 응답 9,180행. 응답자 소득 결측 760행, 수급자 고용 결측 438행이 있다.
네 수급자 프로필 모두의 원래 속성을 확인할 수 있는 응답자는 2,003명, 8,012행이다. 나머지 292명을 완전 프로필 분석에서 제외한다. 주된 표적 모집단은 이 완전 프로필 표본이며, 전체 공개 표본과의 선택 차이를 보고한다. 국가 대표성이나 새 인간 표본이라고 하지 않는다.
Study 2: 2,501명/10,004행. 인구학적 응답자 열이 없으므로 Study 1의 시민을 연결하거나 이념을 만들어 넣지 않는다.
기관·모델·시민의 실제 이름은 모델 입력에 쓰지 않는다. 공개 원자료의 익명 ID는 study1/study2별 이름공간을 사용한다.

5. 본실험 비교 조건 — 하나의 주된 개입
N: 캐나다의 해당 2020년 설문 상황이라는 공통 배경만 제공. 개인의 소득·고용·자녀 정보 없음.
F: 관측된 가구 소득 범주·고용 위험 범주·자녀 유무 제공.
F-I: F와 같되 가구 소득 범주만 제거.
나이·교육·정당·이념·실제 선호·성격은 생성하거나 추론하여 추가하지 않는다. 소득 결측자는 모든 조건에서 해당 문장을 생략한다. F는 '세 가지 사회경제 정보'이지 완전한 디지털 트윈이 아니다.
세 조건에 동일 시민, 동일 수급자, 동일 이름 복원, 동일 제시 순서, 동일 출력 제약을 사용한다. 각 요청은 새 모델 문맥을 사용하고 조건 간 답을 전달하지 않는다. 수집 요청 순서는 시민별 블록 안에서 무작위로 섞어 실행 시점과 조건을 겹치지 않게 한다.
해석: F 대 N은 정보 묶음의 효과, F 대 F-I는 명시적 소득 정보의 추가 효과다. F-I에서도 다른 사실로 소득을 추론할 수 있으므로 소득 관련 모든 지식을 제거한 실험이라고 하지 않는다.

6. 인간 자극과 모델 과제의 복원
Study 1은 두 쌍의 수급자를 보고 각 사람에게 월0–4000CAD를 각각 배분한다. 두 사람의 합계가 4000이라는 예산 제약은 없다.
모델 한 요청은 한 쌍의 두 금액을 생성하고, 한 시민당 두 요청/네 금액을 보존한다. 프로필1/2와3/4를 쌍으로 묶는 것은 기록 순서에 기초한 복원 가정이며 원래 pair ID를 확인한 것은 아니다.
이름은 최종 부록의 성별·민족별 이름 집합에서 복원한다. 원래 개별 이름·언어 조건은 공개 표에 없다. 영어 기본 표기와 프랑스계 백인 이름 민감도를 구분하고, 조건 간 동일한 이름을 사용한다. 정확한 원래 이름 배정을 재현했다고 하지 않는다.
건강: Study1의 Poor health는 기존 질환에 따른 코로나 합병증 위험이다. Study2의 일반적인 poor health와 같게 바꾸지 않는다. 실업: Study1의 위기 관련/무관 실업을 구분하고, Study2의 현재 실업·불완전고용과 섞지 않는다. 자녀 수/연령 문구도 최종 부록대로 구분한다.
기본 모델 요청은 과거의 모델 답을 다음 쌍에 재입력하지 않는다. 개인별 일관성의 근거는 동일 관측 사실이며, 인간의 기억 과정이나 새로운 잠재 성격을 재현했다고 하지 않는다.
원래 slider UI와 JSON 금액 응답은 다르다. 이 연구는 공개 인간 결과를 기준으로 특정 합성 설문 구현을 검증한다. 원래 인간 실험의 완전한 절차 복제가 아니다.

7. 표본, 파일럿, 비용에 따른 사전 축소 규칙
시드20261029, 결과값을 사용하지 않은 추출. 완전 프로필2,003명에서 파일럿32명과 별도 본실험768명 추출. 실제 본실험 후보의 가구 소득: 고304/저252/중140/무응답72명.
파일럿은 JSON유효성·단위·상한·독립적 두 배분의 이해·수신 모델ID·지연·과금·저장 가능성만 점검한다. 인간 효과에 잘 맞는 프롬프트를 고르는 데 쓰지 않는다. 반복 금액·평등 배분은 그 자체로 무효가 아니다.
파일럿 기준: 요청된 형식/범위 유효율95% 이상, 두 금액이 합계 예산으로 잘못 강제되지 않음, 원 응답·비용·모델ID 보존. 기준 미달이면 절차를 수정하고 버전을 남긴 뒤 본실험을 시작한다. 파일럿을 본실험에 합치지 않는다.
기본 계획768명. 예산/처리량만을 근거로 본 생성 전에256/512/768명 중 하나를 선택한다. 동일 무작위 명단의 접두 구간이며 결과 유의성으로 멈추거나 늘리지 않는다. 작은 표본은 작은 집단 차이의 판별력이 낮다는 한계를 남긴다.
주모델 파일럿192요청, 최대 본실험4608요청(768*3*2). 두 모델을 확인할 수 있으면 두 번째 모델의 별도 파일럿16명96요청과 본실험 접두256명1536요청을 우선해 결과의 모델 의존성을 확인한다. 두 번째 모델을 확보하지 못하면 주장을 단일 모델/버전에 한정한다.
Study2 맥락 보조 검증256명*4과제=1024요청. 이는 본실험과 두 번째 모델 확인 이후 우선순위다. 전체 최대 구상7456요청이며, 전송 재시도는 별도로 계수한다. 이것은 실제 호출 수나 예산 승인이 아니다.
모델/비용이 확인되면 파일럿 실제 토큰과 공급자 과금으로 보수적인 전체 상한을 계산한다. 현재 모델ID·지출 한도가 없어 자동 실행은 비활성 상태다. 유료 API가 본질적으로 필수인 설계는 아니다.

8. 주된 추정량과 가설
주표적 gamma = [저소득 시민의 저소득 수급자(3만 대12만CAD) 배분 효과] - [고소득 시민의 같은 효과].
각 조건별 동일한 회귀에서 모든 무작위 수급자 속성과 시민 집단의 상호작용을 포함한다. 가구 소득 미응답·중간 집단은 이 주대조에서 제외하되 전체 평균과 기타 표적에는 남긴다. 효과 차이는 사전에 지정한 두 소득점의 대비이며 기준 범주를 바꿔도 같은 대비를 계산한다.
주오차 theta_F = gamma_F - gamma_H. 인간과 모델의 유의/비유의 여부를 따로 비교해서 차이가 있다고 말하지 않는다.
입력 개입 delta = gamma_F - gamma_F-I. 이는 모델의 명시적 소득 정보에 대한 반응이며 인간 소득의 인과효과가 아니다.
재현 개선은 |gamma_F - gamma_H|와 |gamma_F-I - gamma_H|를 직접 비교한다. 모델이 더 강한 소득별 차이를 만들었다는 사실만으로 더 현실적이라고 하지 않는다. 절대오차 차이의 부트스트랩은 불확실성 요약으로 제시하고 비선형 경계에서 정확한 유의수준을 보장하는 검정이라고 하지 않는다.
부표적 두 개: 시민 고용 위험별 수급자 위기 실업 효과 차이, 시민 자녀 유무별 수급자5세미만 자녀 효과 차이. 모든 부표적을 보고하며 선택적 유의성 홍보를 하지 않는다. 귀무가설 검정을 사용하면 주/부 검정군을 표시하고 Holm 보정을 보고한다.
수급자 공통 효과 beta와 시민 평균 차이 alpha도 함께 보고한다. 복지 지지의 구조를 gamma 하나로 환원하지 않는다.

9. 불확실성과 비교의 표적
모든 인간·모델의 네 과제, 조건별 결과를 같은 시민 ID에 묶어 짝지은 응답자 단위 부트스트랩1000회, 시드고정. 인간-모델 대비를 같은 재추출 안에서 다시 계산한다. 모델 토큰·과제 행·조건 수를 새로운 인간 표본 수로 세지 않는다.
본실험 표본의 인간 결과와 비교하는 것을 주분석으로 하고 전체 완전 프로필 인간 표본과 비교하는 것을 보조분석으로 둔다. 국가 인구 가중치는 공개되지 않았으므로 사용한 척하지 않는다.
모델 버전과 프롬프트를 고정한다. 한 번의 생성은 모델 제공자 업데이트와 모든 디코딩 변동을 대표하지 않으며, 부트스트랩 구간도 그 불확실성을 포괄하지 않는다. 반복 생성이 가능하면 별도 생성 반복으로 기록한다.
차이가 유의하지 않다는 것은 동등함의 증거가 아니다. 동등성 주장을 하려면 정치학적 최소 중요 차이와 표본 해상도를 별도로 정해야 하며, 지금 임의의 허용 오차를 설정해 통과시키지 않는다.

10. 무효 출력과 누락에 대한 평가 방법
Study1 허용 행동은 유한한 금액 범위0–4000. 엄격 JSON정수만 사용하고 설명에서 숫자를 골라내거나 상한으로 잘라 넣지 않는다. 무효 출력은 무효로 기록한다. 의미적 재질문으로 유효 답만 선별하지 않는다.
전송 실패에만 최대2회 재시도하며 모든 시도와 과금을 기록한다. 실패율은 조건·시민 집단·수급자 속성별 보고한다. 모델 거절에 허구의 규칙 기반 답을 채우지 않는다.
고정된 설계 X에서 OLS대비는 w'y이다. 누락된 금액을0–4000의 어떤 허용 행동으로 완성하더라도 가능한 최솟값·최댓값을 계산한다. 완전 사례 삭제와 달리 실패가 무작위라는 가정 없이, 누락된 행동 때문에 주대조가 얼마나 달라질 수 있는지 보여준다.
이 범위는 '무효 응답을 허용 행동으로 완성한 모든 경우'의 범위이지, 거절이 실제 관측 금액이라는 주장이나 인간 선호의 신뢰구간이 아니다. 인간 추정의 불확실성과 별도로 표시한다.
구현: contrast_validity.py. 알려진 인위적 소프트웨어 사례에서32개 극단 완성의 전수 계산과 대조한다. 이 검증을 실제 AI 실험 결과로 세지 않는다.
Study2는 원래 금액 상한이 없으므로 같은 유한 금액 경계를 강제하지 않는다. 무효율과 완전사례 민감도를 보고하고 그 범위 이상의 식별을 주장하지 않는다.

11. 비교 기준과 '좋아 보이는 평균'의 대조군
조건별 인간 평균을 출력하는 상수 대조군은 평균을 정의상 맞히지만 수급자 효과와 집단 상호작용은0이다. 인간 평균을 아는 oracle 소프트웨어 진단으로 표시하고, 예측 성능이나 현실적인 무학습 경쟁자로 제시하지 않는다.
N/F/F-I는 실제 생성 비교 기준이다. 인간 자료로 학습한 간단한 회귀를 추가할 때는 본실험과 다른 시민만 학습하고, 인간 라벨 수·모델 호출·연산 비용을 따로 공개한다. 학습 자료 접근량이 다른 방법을 동일 예산이라고 주장하지 않는다.
실패율을 높여 특정 집단을 지워도 전체 평균은 유지되는 인위적 대조를 통해 평가기가 이를 탐지하는지 확인할 수 있다. 인위적 오류와 실제 모델 오류는 별도 표로 둔다.

12. 별도 정책 맥락 검증 — 주장을 넓히는 조건
Study2에서 원래 배정된 일반 GST/위기 지원 맥락별128명씩 시드로 추출, 각4개 단일 프로필. 관측되지 않은 개인 특성은 주입하지 않는다. 이름·민족의 세부 범주는 일부 합쳐져 있으므로 그 복원/표준화를 공개한다.
배분을 먼저 묻는 합성 과제로 표준화한다. 원 인간 자료의 질문순서 배정이 없고 일부는 배분을 나중에 응답했으므로 이를 동일 절차의 재현이라고 하지 않는다.
인간 평가는 원래 R코드 정제 마스크를 고정해 동일 과제에서 이루어진다. 모델의 큰 금액을 잘 맞는 범위까지 잘라 숨기지 않는다. 모델 무효율/유효 표본을 모두 보고한다.
금액 단위 효과, 동일 인간 기준으로 나눈 효과, 원 논문의 조건별 평균 정규화 결과를 구분한다. 77%/38%만으로 위기가 계층 갈등을 줄인다는 결론은 금지한다.
기존 제도 설명·프로그램명·위기 맥락이 함께 바뀐다. 이를 '순수 위기 프레임 효과'라고 하지 않는다. 두 Study와 alt를 한 사람의 시간 변화로 연결하지 않는다.

13. 모델 입력 격리와 재현
generation_inputs에는 수급자 속성과 각 조건에 허용된 세 가지 시민 사실만 넣는다. evaluation_reference에는 인간 금액·사후 평가·정책 태도와 ID연결을 보관한다. 조건별 agent파일에서 소득 필드 접근을 실제로 제거한다.
모델 요청은 이 대화나 원고 작성 채팅을 이어받지 않는 새 문맥이어야 한다. 인간 수치·가설의 예상 방향·논문 제목·결과 표를 응답자 모델에 제공하지 않는다. 과거 학습 데이터에 원논문이 들어갔을 가능성을 배제할 수는 없다.
폴더 분리만으로 파일을 볼 수 있는 agent의 접근이 차단되는 것은 아니다. runner는 허용된 입력만 읽고, 실제 전송 프롬프트/원응답/hash/returned model ID를 기록해야 한다.
인간 참조 취득일, 코호트 선택 시드, 자극 복원 가정, 모델 정보, 전체 호출/무효/비용을 공개한다. 저장된 응답에서 재분석하는 명령과 새로운 유료 생성 명령은 구분한다.

14. SocioVerse 연구 단위
P: 관측된 사회경제 특성을 가진 익명 시민 ID. E: 해당 설문 맥락과 순차적 수급자 과제. B: 각 사람에 대한 독립적인 배분 금액.
단계는 설문 과제이며 달/년이 아니다. trajectory에는 프롬프트·원답·파싱·실패·모델·비용·과제정보가 남는다. 조건 분기는 같은 시민·같은 자극에서 입력 사실만 바꾼다.
study 폴더 안에 평가기를 구현하여 플랫폼 핵심 변경 없이 재사용하게 한다. 새로운 네트워크나 선거를 붙이지 않아도 Track C의 평가 방법 기여로 제시할 수 있지만, 실제 실행 증거가 필요하다.

15. 결과에 따라 허용되는 결론
평균이 가깝고 집단 대비 오차가 크며 입력 개입으로 그 오차가 달라짐: 해당 합성 시민 구현의 평균 정합성은 정치적 구조 타당성을 보장하지 않는다는 증거. 어떤 집단이 어떻게 왜곡됐는지 한정해 설명한다.
F가 F-I/N보다 인간 대비에 더 가깝고 재검증에서도 유지: 해당 정보·모델·과제에서 시민 정보의 유용성을 뒷받침한다. 모든 복지정치나 개인 디지털 트윈의 타당성으로 확대하지 않는다.
평균부터 크게 실패: 단위/절차 오해를 먼저 진단하고, 기본 배분 재현 실패라는 좁은 결론을 낸다. 그것만으로 정치적 이해관계의 특정 오류라고 하지 않는다.
차이가 불명확하거나 누락 범위가 큼: 이 자료와 비용에서 판별 불충분. 결과를 뒤집는 프롬프트를 탐색해 예쁜 결론을 고르지 않는다.
새 실제 인간 정책효과, 보편 복지 우월성, 계층 갈등의 원인, 투표·입법 연합, 대회 수상·LASS채택은 이 실험의 직접 결론이 아니다.

16. 논문과 발표의 중심 그림
그림1: 인간 대 모델의 시민 소득×수급자 소득 배분 구조. 전체 평균과 상호작용을 구분.
그림2: 세 입력 조건의 인간 대비 오차 및 짝지은 불확실성. 실제 모델 결과만 채움.
그림3: 무효 응답을 삭제한 추정과 허용 행동 완성 범위. 실패 집중이 결론에 미치는 영향.
그림4: 다른 모델/별도 정책 맥락 재검증. 어떤 일반화가 유지되고 깨지는지 표시.
4–8쪽 대회 원고에 문제·근접 연구·설계·핵심 결과·한계와 재현을 우선 배치한다. 프로그램에 소개될 때 설명할 주장은 '모형 선택이 복지 지지의 정치적 구조를 어떻게 재현하는가'다. 표본·모델 수의 크기를 핵심 기여로 삼지 않는다.

17. 남은 시간의 실행 순서
먼저 인간 기준과 자극 복원을 확인하고 프로토콜/입력 해시를 남긴다. 다음은 실제 모델·크레딧·호출 및 저장 경로를 확인하는 작은 파일럿이다. 이후 결과를 보지 않고 모델·표본·비용 상한을 고정한다.
본 생성 → 사전 지정 분석 → 핵심 그림·영문 원고 → SocioVerse 재현 패키지·실제 시연 → 제출 전 실행 검증 순서로 진행한다. API대기 중에는 평가기·원고의 방법 부분·패키지를 작성할 수 있다.
두 번째 모델·맥락 확장 때문에 핵심 본실험·원고·시연이 미완성이 되지 않도록 우선순위를 지킨다. 공식 마감은2026-11-01 00:59KST이다. 수상과 소개는 심사 결과이며 이 설계로 보장되지 않는다.
