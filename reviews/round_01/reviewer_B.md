# Reviewer B — internal AI statistical review

This is an **internal independent AI review, not external venue peer review**. I reviewed only `packet.md`, `packet_manifest.json`, and the four enclosed Python files. I did not inspect raw human data, author context, prior reviews, or another review. All five manifest file hashes matched. Thus the reported archive counts, original assignment, source operationalization and cited literature remain unverified here.

**Judgement: REVISE before main collection.** A narrow descriptive benchmark and a controlled model input intervention are viable. I find no fatal mathematical error in the bounded-action contrast formula. The present packet does not yet determine a reproducible inferential target, an improvement decision, or an adequate precision/failure budget. Those omissions matter before paying for main outputs. Claims about causal human self-interest, national populations, exact human-task replication, or pure crisis effects would require a different design; the packet appropriately disclaims them. There is no model evidence yet and no basis to prefer either direction of the proposed result.

## Ranked findings

### B1 — Major: the finite reference, sampled design, and uncertainty target are not yet reconciled

**Evidence/location.** `packet.md:25–26` targets the retained 2,003-person archive; `46–48` samples a 768-person cohort; `69` requires the same X for humans and model arms; `81–83` prescribes respondent bootstrapping. `prepare_design.py:108–110` exports human outcomes only for selected people, including the pilot.

**Consequence.** There are distinct estimands: the projection on the selected main cohort; the projection on the complete retained archive; and a superpopulation projection. If humans use the full archive and models use the selected cohort, X differs and a contrast difference also incorporates design composition. If all outcomes use the same selected X, the resulting scalar is a cohort projection, not exactly the archive projection. Conditional on fixed X and the recorded complete trajectories, it is a known descriptive quantity; an ordinary respondent bootstrap changes X and invokes a respondent-sampling target. A bootstrap cannot simultaneously be called fixed-design uncertainty without explaining what is random. Sampling 768 of 2,003 without replacement is substantial: the elementary simple-random-sampling finite-population correction is approximately 0.785, illustrating that an ordinary with-replacement bootstrap is not the finite-archive design distribution. This number is illustrative, not a drop-in correction for the regression ratio estimator.

**Concrete fix.** Declare the primary matched-cohort projection and precisely name any population inference. Keep the full retained human projection as a separately labelled descriptive reference. If archive-level model fidelity is the target, specify the finite-population sampling estimator and its design-aware uncertainty. If the target is a hypothetical respondent superpopulation, acknowledge the exchangeability assumption and the limited scope of the available survey. Separately choose whether model outcomes mean one recorded rollout or the expected response of a fixed model/settings over decoding draws. A fixed-cohort expected-response target needs repeat generations to quantify its decoding variability; a cluster bootstrap does not by itself establish that interpretation. Explicitly exclude pilot IDs from the primary main analysis.

**Verification criterion.** An analysis specification identifies the target population, exact row IDs, X, contrast vector, random quantities and interval interpretation. A synthetic finite-population experiment demonstrates coverage for the chosen sampling scheme. Human/model row-order assertions establish identical X in the primary paired analysis.

### B2 — Major implementation mismatch: the enclosed human audit uses a different missing-profile rule

**Evidence/location.** `prepare_design.py:52–57` retains respondents only when all four recipient profiles are complete. By contrast, `study1_interest_audit.py:25–27` drops individual incomplete rows after selecting respondent groups; it does not remove their other judgments. Its CLI reads the entire released Study 1 (`72–73`), rather than the confirmatory cohort. It additionally drops missing human allocations, a condition not checked in cohort preparation.

**Consequence.** The existing human audit is not the proposed primary human reference. Its regression can include partially retained respondents and a different profile distribution. Using that output as gamma_H would silently break the common-design comparison. Outcome missingness could create another human/model row mismatch. The file does describe itself as supplementary, so this is an unresolved implementation boundary rather than evidence that the proposed main analysis has already been run incorrectly.

**Concrete fix.** Implement a separate primary analysis that takes the frozen main ID list, applies the four-profile rule once, checks human allocation availability and range, and constructs one shared X for every arm. Preserve the existing audit only under its different sample label. Do not delete model-invalid rows from that shared X.

**Verification criterion.** A fixture with one missing recipient attribute in one of four judgments excludes all four rows from the primary analysis but demonstrates the supplementary audit's different behavior. Report exact primary IDs and counts, human outcome missingness, 36 design columns for the proposed high/low specification, full rank, and matching ordered rows across outcomes.

### B3 — Major scientific gap: improvement, practical fidelity and sample adequacy lack decision rules

**Evidence/location.** `packet.md:75–83` defines signed discrepancy and an information contrast but only says improvement requires comparing errors. No loss function, meaningful CAD margin, aggregate-plausibility criterion, power calculation or interval-width target is supplied. The 256/512/768 choices are resource prefixes (`46–48`). Human results were already inspected (`5–6`).

**Consequence.** A signed discrepancy can decrease while absolute error increases. Significance of gamma_F − gamma_F-I does not establish improved fidelity, and a null contrast does not establish adequate fidelity. The apparent 768-person sample supplies only 556 high/low respondents and 2,224 judgments for the primary 36-column regression, before failures. Neither 3,072 rows nor the count of requests is the independent sample size. A 256-person second model will have still fewer relevant respondents. There is no evidence yet that any proposed tier can resolve a useful difference.

**Concrete fix.** Freeze, for example, signed errors e_a = gamma_a − gamma_H and improvement D = |e_F| − |e_N|, with D < 0 indicating improvement. Declare a substantive fidelity tolerance and improvement margin in CAD, and define the mean/allocation metric required for the phrase “aggregate allocations look plausible.” Specify which comparisons and endpoints form the multiplicity family, including second-model claims. Simulate precision using the actual fixed profile design, plausible cluster dependence and model/human covariance, plus adverse failures; use a range of effects rather than only the already-seen human result. Choose the resource tier before model outcome inspection. Treat endpoint choice informed by inspected human results transparently rather than implying a wholly outcome-blind discovery design.

**Verification criterion.** A timestamped plan specifies the primary loss, margins, family and resource tier. Simulations report coverage and interval widths or power over a documented scenario grid, and demonstrate that the selected tier can discriminate the declared scientifically meaningful cases. If it cannot, narrow the claim or increase the relevant sample.

### B4 — Major: correct completion bounds may leave the scientific question unidentified

**Evidence/location.** `packet.md:87–94`; `contrast_validity.py:10–29`. The utility gives a sharp interval for one linear contrast conditional on fixed X and independent allowable actions per missing row. The supplied 32-endpoint self-test passes: bounds approximately [−839.00, 2494.33], with the original contrast 192.33 inside.

**Consequence.** Valid mathematics need not yield useful evidence. The exact width is (upper − lower) times the sum of absolute contrast weights on invalid rows. In my balanced 2×2 difference-in-differences fixture, 5% missing in every cell gave [−400, 400], an 800 CAD width. At a stable missing fraction this ambiguity does not disappear by increasing sample size. An arm difference can compound ambiguity from both arms. A small raw invalid percentage can also be concentrated on especially influential profiles. The packet supplies no criterion for whether the resulting bounds can adjudicate fidelity or improvement.

**Concrete fix.** Precompute contrast weights and simulate failure concentration before collection. Report both invalid counts and missing absolute weight. For intervals [L_F,U_F] and [L_I,U_I], bound the linear input contrast by [L_F−U_I,U_F−L_I] when no cross-arm completion restrictions are justified. For fixed observed gamma_H, bound each absolute error using distance from gamma_H to the interval and the maximum endpoint distance; derive the difference of absolute errors from those ranges. Do not substitute differences of interval midpoints. Declare a maximum ambiguity width relative to the substantive margins. Keep identification bounds distinct from sampling confidence intervals, and specify any uncertainty procedure for estimated bound endpoints.

**Verification criterion.** Adversarial fixtures enumerate completions for arm differences and absolute-error improvement, including intervals crossing gamma_H. Report whether conclusions hold for every permitted completion. If sampling inference on partially identified quantities is claimed, validate confidence-set coverage under the declared sampling scheme; otherwise publish descriptive bounds without calling them 95% confidence intervals. Label inconclusive bounds inconclusive.

### B5 — Major implementation gap: pairing is appropriate, but the proposed inference has no implementation or validation

**Evidence/location.** `packet.md:81–83` promises a paired respondent bootstrap with 1,000 draws. None of the enclosed files implements it. `study1_interest_audit.py:43–54` instead computes single-outcome CR1 normal intervals.

**Consequence.** Independently bootstrapping human and model outcomes loses their covariance and can materially misstate fidelity uncertainty. Resampling judgments individually ignores respondent and paired-request dependence. Reusing the full-data X rather than refitting the resampled design estimates another distribution. Ordinary percentile bootstrapping of differences of absolute errors is also nonregular when a true signed error is zero; pairing alone does not fix that problem. A 1,000-draw tail estimate can be noisy after multiplicity adjustment. Singular replicate designs are a foreseeable issue in smaller cohorts and must not be silently filtered.

**Concrete fix.** Resample complete respondent blocks with identical indices and multiplicities across human and every model arm, reconstruct/refit X when using a random-design respondent bootstrap, and prespecify singular-replicate handling. Use new bootstrap cluster labels for repeated draws if computing within-replicate cluster standard errors. For absolute-error comparisons, a conservative route is a joint confidence region for signed errors followed by propagation through the absolute-value map; alternatively validate a method designed for the zero-error boundary. Increase draws until the actual decision and endpoints are Monte Carlo stable.

**Verification criterion.** Identical human/model trajectories yield exactly zero paired discrepancy in every resample; respondent and judgment permutations preserve results; duplicate respondent draws retain their multiplicity. Synthetic coverage checks include near-zero human/model discrepancies and correlated four-judgment errors. My simple identical-trajectory check produced SD 0 under paired resampling versus about 0.100 under independent resampling, illustrating why the covariance matters.

### B6 — Moderate: a group-blind model can have a nonzero group projection contrast

**Evidence/location.** `packet.md:29–35,69–73`; X includes main recipient-factor dummies and interactions with respondent group, but no recipient-by-recipient interactions. Group-specific profile distributions need not coincide. `design_diagnostics.py` checks selected marginal associations, not the full joint support or projection sensitivity.

**Consequence.** A nonlinear response to recipient profiles can yield different additive projections across respondent groups even when the model never sees respondent income. I constructed a full-rank binary-profile example with a group-blind rule y = 4000ab; different group profile distributions produced a 600 CAD group-by-a coefficient. Thus gamma_N ≠ 0 does not itself show implicit income knowledge, and a match to human gamma need not reproduce a human group mechanism. This does not invalidate the explicitly descriptive fixed-design estimand or the controlled F versus F-I comparison.

**Concrete fix.** Report group support, joint-profile overlap, contrast leverage and rank/conditioning. Interpret the primary gamma as the specified projection. Include a group-blind nonlinear comparator and, if making a claim about conditional group responsiveness rather than the archive projection, add a common-profile standardized sensitivity analysis with its target and support restrictions declared. Do not treat zero gamma_N as a required validity check.

**Verification criterion.** The analysis reproduces the synthetic group-blind counterexample and distinguishes projection composition from information intervention. Conclusions about group behavior either survive a justified common-design sensitivity or are restricted to the observed design.

### B7 — Moderate, becoming major for stronger interpretation: the input intervention is not yet operationally locked

**Evidence/location.** `packet.md:37–42,55–65`; original pair/name/language data are unavailable, fresh contexts and randomized request order are promised. `prepare_design.py:92–105` produces arm-labelled input records but no renderer, randomized schedule, isolated runner, validator or output analysis.

**Consequence.** F versus F-I can identify the effect of explicitly supplying income conditional on the other supplied facts, for this model and reconstructed task. It does not identify all income knowledge, the causal effect of human income, or a latent self-interest mechanism. If rendered prompts expose different arm labels/instructions, or requests cluster by arm in time, those changes confound the purported information-only manipulation. Canonical names, reconstructed pairs, language and response format can affect human-model fidelity even when they cancel in an otherwise controlled arm comparison. The two amounts have separate budgets but may still be statistically dependent within a request.

**Concrete fix.** Freeze the model snapshot, decoding/settings, prompt renderer, names, pairs, language, transport-retry rule, randomized/interleaved schedule and raw logs after the validity pilot. Keep arm labels out of prompts. Verify that F/F-I rendered text differs only in the income disclosure and that N lacks respondent facts. Use a small, prespecified subset to check sensitivity to canonical-name choice and pairing/order; limit transfer claims if results are sensitive. Keep historical outcomes and linkage unavailable to the runtime beyond whitelisted fields. Define whether partial valid answers in otherwise malformed pair responses are retained or both are invalidated.

**Verification criterion.** Byte-level prompt diffs, independent input-access checks, reproducible randomized schedules and complete request/response logs establish the intended intervention. Missing-income cases supply identical F and F-I rendered content; deterministic identical settings should then agree, while stochastic differences are treated as generation noise. A second model is evaluated on the same frozen respondent subset before either model's results determine follow-up selection.

### B8 — Moderate: the selected target is defensible, but missingness limits must persist through reporting

**Evidence/location.** `packet.md:23–35`; `design_diagnostics.py` explicitly disclaims certification of assignment. The supplied retention counts imply approximately 93.6% retention among high-income and 81.1% among low-income respondents.

**Consequence.** The complete-profile target avoids pretending that missing regressors are known, but it does not recover the released sample or national population. The 12.5 percentage-point retention difference makes broad extrapolation particularly questionable. A permutation diagnostic under respondent-block exchangeability cannot reconstruct the original factor-assignment process, establish missing-at-random preprocessing, or turn respondent income into a randomized attribute. Nonuniform margins alone do not establish experimental failure either.

**Concrete fix.** Keep complete-profile descriptive claims primary. Report observed retained/excluded differences and all eligibility rules. Treat any imputation or weighting sensitivity as assumption-dependent. Investigate assignment/preprocessing provenance if causal recipient-attribute interpretation is desired; do not require a uniform distribution merely because profiles were randomized.

**Verification criterion.** Every headline identifies the retained target; the exclusion audit reports outcomes and observed covariates where available, without claiming to recover missing profiles. Any causal AMCE or full-sample claim has separate provenance and identification evidence. The proposal can proceed without that stronger claim.

### B9 — Minor concrete bug: the point-identification flag depends on irrelevant missing rows

**Evidence/location.** `contrast_validity.py:28–29` sets `point_identified_in_fixed_design = known.all()`.

**Consequence.** A missing row with zero contrast weight leaves the target exactly identified, but the utility says otherwise. My full-rank fixture X = [[1,0],[1,0],[0,1]], y = [10,20,missing], c = [1,0] returns lower = upper = 15 and the flag false. The bounds themselves remain correct.

**Concrete fix.** Base the identification flag on zero completion width/zero relevant unknown weights, with an explicitly documented numerical tolerance rather than requiring all outcomes to be observed. For the reusable component, favor QR/SVD-based weights over normal equations and report conditioning; a single well-conditioned synthetic test does not certify numerical stability across arbitrary designs.

**Verification criterion.** Add zero-weight missingness, all-valid, all-invalid, sign-changing weights, shape/rank/range rejection and ill-conditioned-design fixtures. Verify the strict JSON integer policy in the actual validator rather than assuming the numerical bounds utility enforces it.

## Smallest viable analysis and the result that would change this judgement

Keep Study 1, one fixed model, the three arms, and one primary high-versus-low / 30k-versus-120k contrast. Retain N to assess whether the fact bundle improves fidelity and F-I to isolate explicit income disclosure. The 556 high/low people already present in the candidate 768-person cohort would require 3,336 main pair requests, before retries; the other 212 do not contribute to this primary contrast. This is a possible reduced scope, not a claim that 556 is adequately powered. Select the final tier through the precision analysis. Defer the context extension and secondary confirmatory mechanisms; a small second-model replication on frozen shared respondents is more informative than expanding to a different study before the primary result is interpretable.

Before collection, freeze the target, primary IDs, renderer/settings, loss/margins, uncertainty method and failure rules. Analyze matched rows jointly; publish signed errors, the information contrast, the F-versus-N fidelity loss difference, aggregate diagnostics and completion bounds. Report all outcomes, including an inconclusive result.

The smallest convincing empirical result would be a held-out, fully logged three-arm comparison in which the joint uncertainty region and all allowed failure completions adjudicate a prespecified meaningful fidelity difference or demonstrate adequate fidelity within a prespecified tolerance. The direction may favor F, N, or show no practically meaningful difference. A precise negative or equivalence result is useful; an uninformative p-value or a widening failure interval is not. A second frozen model producing compatible or clearly model-specific results would support broader usefulness. This evidence would change the judgement from revise to proceed with a narrowly scoped empirical contribution. The packet alone cannot establish novelty relative to the listed papers, and the bound identity by itself is insufficient as the scientific contribution.
