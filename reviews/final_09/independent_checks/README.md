# Original independent review checks

These are verbatim reviewer scripts and aggregate outputs from the fresh-context
review, retained as evidence of what each reviewer checked. They refer to the
original temporary review/private paths and are not the portable project runner.
The portable reproduction command is scripts/reproduce_handoff.py. Raw source,
private cohort linkage and human-level prediction NPZ files are not included.
The source packet and manifests were not replaced by the revised code. Tests
in that snapshot number67; post-review author fixes are separately verified.
